# @underground-moto/ui

Design system y componentes de UI compartidos entre `apps/storefront` y, a futuro, cualquier otra app (ej. un panel propio). Se crea a partir de la Fase 1, cuando exista una identidad visual definida (logo, paleta, tipografía — ver `ROADMAP.md`, Fase 0).

Objetivo: que la estética "underground/motera" de la marca viva en un solo lugar (tokens de color, tipografía, componentes base) en vez de duplicarse dentro del storefront.
