# 0002 - Identidad visual mínima

## Decisión (marca base)

- **Paleta de marca**: negro `#0A0A0A`, hueso `#F2F0EB`, acento violeta `#9B4DFF` ("Violeta luna llena").
- **Tipografía de marca**: Anton (display/logo, gráficos grandes) + Space Mono (texto utilitario: tags, precios, UI).
- **Wordmark**: "TEKKO" en Anton sobre fondo negro, con punto de acento en violeta.

## Paletas alternativas (reservadas para diseños de prendas puntuales, no para la marca base)

- **Rojo señal nocturna**: negro `#0A0A0A`, hueso `#F2F0EB`, acento rojo `#E8232B`.
- **Teal + naranja**: negro `#0A0A0A`, teal `#00C2B2`, naranja `#FF6A1A`.

## Tipografías alternativas (reservadas para gráficos/drops puntuales, no para la marca base)

- **Gótica/metal**: UnifrakturCook (display) + Oswald (utilitaria). Dramática, la más "underground/metal"; poco legible en tamaños chicos, usar solo en gráficos grandes.
- **Stencil/industrial**: Wallpoet (display) + Rajdhani (utilitaria). Mecánica, conecta con el significado de "Tekko" (armadura de hierro).

## Referencias de estilo

Streetwear japonés + cyberpunk nocturno + moto culture: siluetas oversized, gráficos grandes de espalda (máscaras, kanji, ilustración anime/manga), base oscura con acentos neón, detalles techwear en piezas puntuales.
